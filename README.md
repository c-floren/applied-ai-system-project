# 🎵 Music Recommender Simulation (AI-Augmented)

![Music Recommendation System](images/MusicRecommendation.png)

## Project Summary

SoundMatch 2.0 is an AI-augmented music recommender. The user-facing answer is generated by Google's Gemini model in one of two modes selected from a CLI menu at startup:

1. **Naive LLM** — Gemini recommends 5 songs from its own training data based on the user's taste profile. No catalog access. This is the demonstrably weaker mode and exists to make the contrast visible.
2. **RAG (retrieval-augmented)** — The original rule-based scorer runs first as a *retriever*, pulling the top 10 candidate songs from `data/songs.csv`. Those candidates (with full attributes) are passed to Gemini, which re-ranks down to 5 and writes a personalized explanation grounded in the candidate attributes. Gemini is constrained to pick only from the retrieved list.

The original rule-based scorer is preserved internally — it powers the RAG retriever and still backs `Recommender.recommend()` for the test suite — but it is no longer the user-facing answer.

---

## How The System Works

**Songs (catalog):** genre, mood, energy (0–1), tempo, valence, danceability, acousticness. 18 songs in `data/songs.csv`.

**User profile:** favorite genre, favorite mood, target energy, acoustic preference.

**Rule-based scorer (now used as the RAG retriever):** Each song is scored 0–100 with weights — Genre 40% (exact match), Mood 30% (exact match), Energy closeness 15%, Danceability 10% (target 0.7), Acousticness 5%. Songs are ranked and the top 10 are passed to Gemini in RAG mode.

**Naive LLM mode:** Gemini receives only the user profile and is asked to return 5 songs in JSON. It does not see `data/songs.csv` and frequently hallucinates titles.

**RAG mode:** Gemini receives the user profile *and* the 10 retrieved candidates with their attributes. It is instructed (in the system prompt) that it must pick only from the candidate list and that explanations must cite concrete attributes. The output is parsed back to song records from the catalog.

**Why this design:** The rule-based scorer is transparent but rigid — it ignores genre similarity and treats unknown genres silently. Gemini in RAG mode can reason about taste in language while staying anchored to real catalog data. The naive mode is included so the comparison is honest.

## Getting Started

### Setup

1. Create a virtual environment (optional but recommended):

   ```bash
   python -m venv .venv
   source .venv/bin/activate      # Mac or Linux
   .venv\Scripts\activate         # Windows

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Set up your Gemini API key:

```bash
cp .env.example .env
# then edit .env and paste your key from https://aistudio.google.com/app/apikey
```

4. Run the app (interactive menu):

```bash
python -m src.main
```

You'll be prompted to pick a user profile and a mode (Naive LLM or RAG). To sweep every profile through every mode for the writeup, use:

```bash
python -m src.main --all
```

LLM responses are cached to `.cache/` (keyed by prompt hash) so reruns of the same profile+mode don't burn API quota and produce identical output for screenshots.

### Running Tests

Run the starter tests with:

```bash
pytest
```

You can add more tests in `tests/test_recommender.py`.

## Experiments You Tried

The headline experiment is the **rule-based vs Naive LLM vs RAG** comparison across the 8 user profiles, especially the adversarial ones:

- **Ghost Genre (k-pop):** The rule-based scorer silently fell back to mood/energy and returned weak matches. Naive LLM happily invented k-pop songs that don't exist in our catalog. RAG correctly noted that k-pop isn't in the catalog and picked the closest available match by mood and energy from real candidates — the only mode that handles missing genres honestly.
- **Zero Energy Rocker:** The rule-based scorer ranked Storm Runner (energy 0.91) at the top despite the user wanting energy 0.05, because genre+mood weights overwhelmed the energy signal. RAG's re-ranking pulled lower-energy candidates forward in the top 5 even when they had a slight genre mismatch.
- **Sad but Hyper:** Naive LLM tended to return well-known sad songs that were actually low-energy, ignoring the contradiction. RAG explicitly acknowledged the contradiction in its explanations.
